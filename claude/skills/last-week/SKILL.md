# last-week

`~/.claude/weekly-review/latest.md` を読み、先週の作業途中の会話を利用者に見せる。

## 手順

1. `~/.claude/weekly-review/latest.md` を Read で読む。
   - 無い、または 1 行目の作成日時が 7 日より前なら、`~/.dotfiles/bin/claude-weekly-review` を実行して作り直してから読む。
2. Issue ごとに、次を短く示す。
   - Issue の題名と URL
   - 各会話のタイトル、最終日時、ブランチ
   - 最後の応答の抜粋から読み取れる「どこまで済んだか / 次に何をするか」を 1〜2 行で
   - 再開コマンド（ファイルにある `cd ... && claude --resume ...` をそのまま）
3. 最後に、どの Issue から再開するか利用者に聞く。

## 注意

- 抜粋に書かれていない進捗を推測で補わない。読み取れなければ「抜粋からは不明」と書く。
- 同じ会話が複数の Issue に出ることがある（最初のプロンプトに複数の Issue URL があった場合）。そのまま示してよい。
